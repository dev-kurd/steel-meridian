01 · Summary

All but one of the game's 86 art assets are placeholders

Steel Meridian loads every drawing from its assets folder at start-up. The art was written by the programmer to make the game playable. It is original to this project, so it is safe to ship, but it was not made by an artist. Only the Heavy Factory has a team-made model.

02 · Delivery requirements

Vector 2.5D, one folder per asset, recolourable per army

Nothing is embedded in the code. Replacing a file in assets/ and reloading the game is enough to see new art.

RequirementDetail
StyleVector 2.5D, drawn for a 2:1 isometric map (26.57°).
Scale1 unit = 1 world pixel. A heavy tank is 38 × 28; a light tank about 26 × 19; a standard structure 60–92 across.
Format A
plan-view model		An SVG drawn from straight above, with a height on each shape. The game raises it into 2.5D, turns it to any heading and casts its shadow. Used by all current buildings, turrets and units. Specification: assets/README.md.
Format B
scripted model		A self-animating SVG script, as delivered for the Heavy Factory. Suits large structures with complex moving parts. It does not turn, so it needs one drawing per facing. Specification: docs/art/art-style-guide.md.
Structure statesOwned, neutral (grey), destroyed (wreck), fortified, working (lights, smoke, moving parts), and upgrade levels where listed.
Unit statesAny heading; turret turns separately from the hull; muzzle flash when firing; moving tracks or legs; ground shadow.
Small graphicsPlain SVG. Flags are 72 × 48. Cursors carry a hot-spot.
OriginalityThe game is going commercial. All art must be original to the team or properly licensed, with no likeness to an existing game's units or structures.

03 · Buildings, continued

Support structures and the six turrets

Turrets

Each is drawn to sit on the Turret Pad and turn to any heading. Each needs a muzzle flash and a "reloaded" look. Two upgrades change strength only, not appearance.

Sizes are in world pixels. The Light and Medium factories share one placeholder today; they should be sized so their own tank classes fit through the gates, as the Heavy Factory now does.

04 · Ground units

Fifteen tanks: five roles in three weight classes

A heavier class should read as larger and more heavily armoured at a glance. Folder names are the role code plus the class number: units/bt2 is the Heavy Lancer.

06 · Environment, effects, flags · 07 · Interface

Forty-two small graphics, each a plain SVG

Props

Effects

Explosions, shells, missiles, laser beams, tracer fire, sparks and track marks are drawn by code today. Drawn versions would be new assets and need a small code change to load them.

Flags

Interface icons and cursors

Menus, panels, the minimap frame and health bars are drawn with CSS and code, not image files. A visual redesign of those is a design task rather than an asset swap. The application icon is icon.png / icon.ico.

Suggested order of work

  1. Light and Medium Tank Factory modelsAlready promised; they complete the factory set.
  2. Heavy Factory additionsFortified and upgrade-level visuals.
  3. The 15 tanksAgree one design per role, then scale it to three classes.
  4. Command Core and VanguardThe two assets that identify each army.
  5. Remaining structures and the six turrets
  6. Robots, aircraft, Engineer, Supply Truck
  7. Props, effects, flags, icons, cursorsSmall; a second artist can work in parallel.
  8. AudioMusic, missing effects, announcer licence check.

Open questions for the team

  • Which format will the team deliver in: plan-view models (A), scripted models (B), or a mix by asset type?
  • Should structures other than the Heavy Factory grow to match its new, larger scale?
  • Skirmish for 2–4 players is planned. Are four team colours enough?
  • Should terrain, water and battle effects stay generated by code, or become drawn assets?
