Candidate sounds for the Anti-Air rocket launch, tank demo only
===============================================================

These 2 recordings are used by the options in the tank demo (the row "Anti-Air rocket sound"), together with the game's own
recordings in sounds/. They are not used by the game yet: once the owner has chosen, the chosen ones move to the game's
sounds/ folder (as WAV) and the rest are deleted.

Both come from OpenGameArt and are released under CC0 1.0 (public domain; no credit required), as each page states.
Downloaded 2026-11-21.

File here        Original file     Author       Page
k_rocket.ogg     rocket_01.ogg     rubberduck   https://opengameart.org/content/50-cc0-sci-fi-sfx  (sci-fi-sfx.zip)
k_thruster.ogg   space_ship.ogg    EZduzziteh   https://opengameart.org/content/thruster

The files are unchanged copies; the demo changes speed, loudness, start point, fade-in and length when it plays them (see
ROCKET in ../sfx.js). The three options are shaped after the short weapon sounds of the original State of War, which were
only measured (length, attack, pitch) as a reference. No audio of the original game is in this repo.
