Candidate sounds for the Heavy Special tank (Graviton), tank demo only
======================================================================

These 13 recordings are options to choose from in the tank demo (the row "Heavy Special sound"). They are not used by the
game yet: once the owner has chosen, the chosen ones move to the game's sounds/ folder and the rest are deleted.

Source: "150 Combat Sound Effects", compiled by untamedpixels, https://opengameart.org/node/195932
(150gameeffectsounds.zip, downloaded 2026-11-21). It is the same pack sounds/README.txt at the repo root names.
Every file in the pack is CC0 1.0 (public domain; no credit required), as its LICENSES.txt states.
