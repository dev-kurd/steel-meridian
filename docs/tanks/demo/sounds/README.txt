Candidate sounds for the Anti-Air rocket launch, tank demo only
===============================================================

These recordings are options to choose from in the tank demo (the two rows "Anti-Air rocket sound"). They are not used by the
game yet: once the owner has chosen, the chosen ones move to the game's sounds/ folder (as WAV) and the rest are deleted.

The five of the second set come from OpenGameArt and are released under CC0 1.0 (public domain; no credit required), as each page states.
Downloaded 2026-11-21.

../sfx.js).
