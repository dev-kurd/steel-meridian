Candidate sounds for the Anti-Air rocket launch, tank demo only
===============================================================

These 5 recordings are options to choose from in the tank demo (the row "Anti-Air rocket sound"). They are not used by the
game yet: once the owner has chosen, the chosen ones move to the game's sounds/ folder (as WAV) and the rest are deleted.

All five come from OpenGameArt and are released under CC0 1.0 (public domain; no credit required), as each page states.
Downloaded 2026-11-21.

File here        Original file           Author              Page
k_rocket.ogg     rocket_01.ogg           rubberduck          https://opengameart.org/content/50-cc0-sci-fi-sfx  (sci-fi-sfx.zip)
k_missile.wav    missile.wav             mikeask             https://opengameart.org/content/missile-sound
k_thruster.ogg   space_ship.ogg          EZduzziteh          https://opengameart.org/content/thruster
k_engine.wav     rocket_engine.001.wav   theMinesAreShakin   https://opengameart.org/content/rocket-engine
k_launch.wav     launch.wav              qubodup             https://opengameart.org/content/rocket-launch  (launch.7z)

The files are unchanged copies; the demo changes speed, loudness, start point and length when it plays them (see ROCKET in
../sfx.js).
